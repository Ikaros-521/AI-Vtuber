此文件夹存放直播弹幕监听的JS脚本。  
如何使用？  
浏览器打开你需要监听的直播间，然后F12打开控制台，粘贴脚本里的代码到控制台，回车运行

「直播弹幕监听助手（洛曦）」这一路：

* `洛曦 直播弹幕监听 转发至本地WS服务端.js`：斗鱼、拼多多、淘宝、1688、快手2 等平台通用，在直播间页面 F12 粘贴运行，它把消息用 websocket 推给本程序。
* `douyu_ws_client.js`：早期只给斗鱼用的版本，推的是同一种弹幕消息。

两个脚本连的都是 `ws://127.0.0.1:5001`，这个地址必须和 `通用配置 → 功能管理 → 平台相关 → 直播弹幕监听助手` 里的监听IP/监听端口一致（对应 `config.json` 的 `live_monitor_assistant` 段）。脚本自己的地址也能在助手面板里改，两边改任意一边都可以，但要一致。

脚本会推 `comment`（弹幕）、`gift`（礼物）、`like`（点赞）三种。弹幕和礼物都会接进本程序对应的处理流程，点赞没有对应流程会被忽略。



两种脚本的礼物字段不一样（旧版直接给 `gift`，新版给 `data.gift` 或 `content`），本程序三种都认。



礼物只能从直播间页面上扒到文字，拿不到数量和价格，所以按 `1 个 / 0 元` 记录。想让这条路触发礼物感谢播报，需要把 `感谢 → 礼物感谢最低值`（`thanks.lowest_price`）设成 `0`，否则会被「低于最低值不感谢」挡掉；按礼物名走的积分、按键映射、自定义命令不受影响。
